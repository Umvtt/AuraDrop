## What's new in 0.2.0

AuraDrop is now a meme maker and interactive canvas, not just a glass card builder.

- **Canvas with layers:** text and meme captions, pictures and GIFs, stickers, shapes, glass panels and buttons. Move, resize, rotate and snap them; double-click text to type.
- **Buttons that do things:** open links, play sounds, confetti, shake the screen, show popups, show or hide layers, and jump between pages.
- **Pages:** build quizzes, stories and soundboards with page transitions.
- **Templates:** classic meme, two-panel, reaction, soundboard, link hub, quiz and glass card, in any canvas size.
- **Much more customization:** 11 fonts (including Impact-style meme text), outlines, shadows and highlights, picture filters (deep fry!), gradients, aura backgrounds and 9 animations.
- **Preview first:** opening a `.auradrop` file shows it ready to play. Press **✏️ Edit** to change it.
- **Save .auradrop** now sits right next to **Export PNG**, plus a new **Web page** export: one `.html` file that works in any browser, buttons included.
- **Required updates:** AuraDrop checks for new versions and updates itself in one click, keeping your settings.
- Old `.auradrop` files from 0.1 open automatically.

## Install

1. Download **AuraDrop-Setup-0.2.0.exe** below.
2. Run it. Windows SmartScreen may warn because the installer isn't code-signed yet: click **More info → Run anyway**.
3. Pick your options and click **Install**. No administrator rights needed.

Needs Windows 10 or 11 (64-bit). Setup installs Microsoft Edge WebView2 if your PC doesn't have it yet.
Already on 0.1.0? Run the new installer once. From 0.2.0 on, AuraDrop updates itself.
